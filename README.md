# RaveSpin

The idea behind Rave-Spin, is using a mixed-reality (XR) headset, such as the Meta Quest 3S, give experienced DJ’s (Disk Jockeys) the opportunity to make and mix music, without the need for the usual physical equipment being present, thus allowing them to mix and play on-the-go.
